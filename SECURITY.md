## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not report it through a public GitHub issue.

Please use GitHub's private vulnerability reporting feature to submit a report through the Security section of this repository.

Include a description of the vulnerability, steps to reproduce it, the affected version or commit, and any potential impact you have identified.

Please do not include sensitive data, credentials, video footage, vehicle information, or other personal data unless it is strictly necessary to demonstrate the vulnerability.
